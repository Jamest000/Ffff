# Flyme小窗 · AOSPA（小米 13 / Android 17 Root 适配版）

专为 **类原生 AOSPA（Android 17）+ Root** 打造的小窗增强工具。基于系统原生 Freeform 自由窗口接口 + Root 任务控制 + 悬浮手势 + 通知监听实现，无需 Hook `SystemUI`，升级 ROM 不易崩溃。

## 内置功能（默认全开，设置页可单独开关）

### 1. 取消 / 关闭小窗手势
- **顶部悬浮条上滑取消**：检测到有小窗运行时，屏幕顶部自动浮现细长控制条，向上轻滑触发震动反馈并直接取消当前小窗。
- **顶部悬浮条双击取消**：连续点击两次顶部细条直接取消当前小窗。
- **顶部悬浮条下滑转全屏**：向下拉顶部细条，将当前小窗切回全屏模式。
- **屏幕边缘一键取消手势**：在屏幕左侧（可切换右侧）中上边缘向内滑或下滑，直接取消当前小窗，无需点小窗右上角叉号。

### 2. 呼出小窗手势
- **左下角 / 右下角斜向内滑**：Flyme 经典底角手势，斜向上内滑弹出小窗快捷应用面板。
- **侧边栏滑出**：屏幕右侧中段细条向内滑呼出同一快捷面板（底部也带“一键取消当前小窗”按钮）。

### 3. 悬浮通知直开小窗（免 LSPosed）
- 收到微信、QQ、Telegram 等白名单应用新消息时，顶部弹出轻量悬浮横幅：
  - **点击或下拉横幅**：直接以自由小窗打开该应用。
  - **上滑横幅**：立即忽略并收起；锁屏状态自动不弹窗。

## 3 步云编译生成 APK（免装 Android Studio）

1. 在 GitHub 新建一个仓库（公开或私有均可），把本压缩包解压后的所有文件（包含 `.github/workflows/build.yml`）上传到仓库根目录。
2. 打开仓库顶部的 **Actions** 页面，等待 `Build AospaFlymeFreeform APK` 自动运行完成（约 2–3 分钟，也可点击 `Run workflow` 手动触发）。
3. 进入该次构建记录，在底部 **Artifacts** 区域下载 `AospaFlymeFreeform-AOSPA-A17-APK`，解压后安装里面的 `app-debug.apk` 即可。

> 如果电脑已安装 Android Studio，也可以直接打开本目录执行 `Build -> Build APK(s)` 本地编译。

## 小米 13 + AOSPA A17 首次使用步骤

1. 安装 APK 后打开应用，授予 **Root 权限**（Magisk / KernelSU / APatch）。
2. 点击首页 **授权悬浮窗** 和 **授权通知监听**。
3. 点击 **一键开启并启动**（会自动写入系统自由窗口开关并启动后台手势服务）。
4. 可在「小窗比例与手势微调」里打开 **显示手势热区色块**，直观确认蓝（底角呼出）、绿（侧边呼出）、红（边缘取消）、橙（顶部取消条）四个热区位置后关闭调试开关。
5. 建议在系统电池设置中将本应用设为 **不受限制**，防止后台手势服务被系统回收。
